# Saat Tarih

Canlı saat, bugünün tarihi ve dünya saatleri (TR / EN). Bir Bumba Life ürünü.

```sh
npm run build   # dist/ üretir (bağımlılık yok)
npm test        # derler ve kalite denetimini çalıştırır
npm run serve   # http://localhost:8080
```

Ayrıntılar, kararlar ve Bumba Genel Standartlar için [CLAUDE.md](CLAUDE.md).
